# Учебный проект Laravel (первое задание)

## Требования
  - PHP 8.5.10+
  - Composer

## Установка и запуск
  1. Клонировать/скачать проект (или «открыть папку»).
  2. composer install
  3. Скопировать .env.example в .env
  4. php artisan key:generate
  5. php artisan serve
  6. Открыть в браузере:
     - http://127.0.0.1:8000/one
     - http://127.0.0.1:8000/two

## Краткое содержание страниц:
    первая страница - тайтл, сообщение и ссылка на вторую старницу
    вторая страницы - тайтл, сообщение и ссылка на первую старницу
